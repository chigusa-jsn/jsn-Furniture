# jsn-Furniture

NeoForge 1.21.1 の家具MOD。洋風・和風の家具が約320種類。

## できること
- **座る**：椅子・スツール・ベンチ・ソファ・座布団・こたつ・お風呂・トイレ（右クリック。Shift で降りる）
- **寝る**：木の枠のベッド（11種類の木）・布団。バニラのベッドと同じように寝られて、リスポーン地点になる
- **物を入れる**：机・タンス・クローゼット・キッチンカウンター・冷蔵庫・賽銭箱
- **つける／消す**：ランプ・シャンデリア・天井ライト・街灯・コンロ・行灯・提灯・石灯籠・囲炉裏（右クリック）
- **開け閉め**：カーテン（16色）・すだれ・障子・ふすま
- **飾る**：ショーケース（アイテムを1つ入れると、くるくる回る）
- **水をくむ**：シンク（バケツ・ガラスびん）
- **音**：風鈴（26種類。ガラス・南部鉄器・真鍮・陶器・竹で音が違う。風でゆれて鳴り、雨の日はよく鳴る。右クリックでも鳴る）、鹿威し（ときどきカコン）

## 家具の一覧
- 木ごと（オーク・トウヒ・シラカバ・ジャングル・アカシア・ダークオーク・マングローブ・サクラ・竹・真紅・歪み）
  椅子・スツール・ベンチ・テーブル・ローテーブル・机・壁の棚・タンス・クローゼット・キッチンカウンター・ちゃぶ台・ベッド
- 色ごと（16色）：ソファ・カーテン・座布団・のれん
- 洋風：冷蔵庫・コンロ・シンク・お風呂・トイレ・テーブルランプ・フロアランプ・シャンデリア・天井ライト・壁かけ時計・鏡・観葉植物・ショーケース・レジ・立て看板・街灯・パラソル
- 動物：動物の風鈴（白猫・黒猫・三毛猫・狐・うさぎ・たぬき）・招き猫（白・金）・お稲荷さんの狐・信楽のたぬき・だるま（赤・白）・ぬいぐるみ8種・キャットタワー・犬小屋・ペットベッド（16色）・えさ皿・水皿・猫クッション（4色）・肉球ラグ（16色）・くまのソファ・ねこのソファ
  - ペットの家具を右クリックすると、リードでつないだ動物か、近くの自分のペット（猫・犬・オウムなど）が座る。もう一度右クリックで降りる
- 和風：こたつ・布団・障子・ふすま・すだれ・行灯・提灯（赤・白）・石灯籠・囲炉裏・畳・半畳・掛け軸（3種）・盆栽・和傘・賽銭箱・鳥居（柱・笠木・貫）・鹿威し・風鈴

クリエイティブタブ「jsn家具（洋風）」「jsn家具（和風）」。全部作業台で作れます（JEI でレシピを確認できます）。

## 作り直し
- `python3 tools/gen.py`：家具の一覧・モデル・テクスチャ・レシピ・名前
- `python3 tools/gen_sounds.py`：風鈴・鹿威しの音
- `python3 tools/render_preview.py <バニラのtextures/blockのフォルダ> build/preview/all` → `python3 tools/build_catalog.py build/preview/all build/preview/catalog.html`：家具カタログ（立体の絵の一覧）
